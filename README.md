# Prédiction des prix immobiliers par Régression Linéaire

Projet de Machine Learning classique pour débuter, basé sur le dataset California Housing de Scikit-Learn.

## Fonctionnement
L'objectif est d'utiliser une régression linéaire pour prédire la valeur médiane des logements en fonction de différentes variables explicatives (données démographiques et géographiques).

## Visualisation
Le script génère un graphique de dispersion comparant les valeurs réelles du marché aux prédictions du modèle, ce qui permet d'évaluer visuellement sa précision.

## Bibliothèques utilisées
- Python
- Scikit-Learn
- Pandas / Matplotlib
